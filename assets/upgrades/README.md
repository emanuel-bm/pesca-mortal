# Artes de melhoria

Geradas com a ferramenta integrada ImageGen, usando `vitalidade.png` como referência. Título, nível, descrição e valores são desenhados pela interface do jogo.

## Prompt comum

Generate ONE standalone game upgrade card asset matching the reference Vitalidade card's exact visual family: chunky crisp pixel art, warm cream parchment, stepped golden rectangular border with dark brown pixel outlines, portrait 2:3 shape, flat straight-on view, centered and closely framed. Replace its heart and leaves with this unique central symbol: [subject]. Make the symbol large and easily recognizable when displayed at 110x160 pixels. Small thematic corner emblems in opposing corners and restrained gold ornament. Match the reference border, parchment palette, pixel density, canvas size and card proportions. No heart motifs. Absolutely NO text, letters, numbers, titles, level badges, or UI labels anywhere. All information will be drawn dynamically outside the card by the game. Opaque parchment inside card; transparent outside its silhouette, no background scene or drop shadow.
