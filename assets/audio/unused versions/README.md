# Unused versions — rugido do Minhocão

Arquivos de comparação preservados no repositório, fora da versão distribuída.
A pasta contém `.gdignore` e é excluída em todos os presets de exportação.
Não colocar esta pasta no `.gitignore`: os arquivos devem continuar versionáveis.

| Arquivo | Versão |
| --- | --- |
| `minhocao_roar.wav` | Arquivo usado antes da aprovação da V5, igual à V1. |
| `minhocao_roar_v0.wav` | Reconstrução da versão mais aguda anterior. |
| `minhocao_roar_v1.wav` | Versão com tom reduzido e agudos suavizados. |
| `minhocao_roar_v2.wav` | V1 com sustentação de um segundo. |
| `minhocao_roar_v3.wav` | Tom da V0, sustentação até 1,5 s, ataque de 40 ms. |
| `minhocao_roar_v4.wav` | V3 com ataque de 200 ms. |

A V5 aprovada está em `../minhocao_roar.wav`: ataque de 400 ms, volume 30%
menor, sustentação até 1,5 s e queda no último meio segundo, duração total de 2 s.

Os scripts desta pasta preservam o processo de geração das versões antigas;
operam dentro do arquivo histórico, sem substituir o som oficial.
