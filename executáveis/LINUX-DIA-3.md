# Festival — Linux — Dia 3

Baixe `pesca-mortal-festival-dia3-linux-v0.5.0.tar.gz` pelo botão **Download raw file** do GitHub.
Este é o pacote atualizado para o Dia 3, baseado na versão 0.5.0.

Extraia o TAR.GZ e execute o arquivo `.x86_64`. Se necessário, conceda permissão com `chmod +x`.
Feche o jogo anterior antes de abrir esta versão. Não apague a pasta de dados do jogo.

Inclui os 50 recordes recuperados: 27 do Dia 1 e 23 do Dia 2.
Novas partidas entram no Dia 3. A base é incorporada também em instalações existentes,
preservando partidas locais adicionais. Esta versão funciona offline.

**Recordes do Festival** permite filtrar Dia 1, Dia 2, Dia 3 ou Todos os dias.
Normal classifica por maior tempo; Boss Rush por menor tempo, apenas vitórias.
Enter no campo do nome salva e sai. Sem nome, apenas sai.
