# Congelar classificações globais encerradas

Uma mudança de X ou Y em vX.Y.Z inicia uma nova versão competitiva. A classificação global anterior é preservada com os nomes usados no encerramento e deixa de aceitar resultados, incluindo partidas offline enviadas depois e partidas de clientes antigos, para que seus campeões sejam definitivos. O histórico pessoal continua preservando as partidas na versão correspondente; aceitar envios globais tardios foi descartado porque mudaria os vencedores já apresentados em Lendas.
